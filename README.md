# Cellini

Cellini is an extensible, customizable browser for files and other browsable objects, written in C#.
Browsable objects can be browsed in different paradigms, so called facets.

## Origin
Cellini is a new approach to slop-implement an alternative to lvl2 my other meta and application runtime.
This is also used as an AI sample project with a direct reference project already existing, even though the scope is different.

## Target Platforms

Windows 10 and Arch Linux.
